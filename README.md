
# Insurance Cost Prediction using Basic Machine Learning Models

This project is a Data Science fundamentals project from my BS Data Science coursework. It predicts **annual medical insurance charges** based on features like age, BMI, number of children, gender and smoking status.

We used a dataset from Kaggle, cleaned it, visualized relationships, engineered features, and applied machine learning models to predict insurance costs.

The full project report was submitted as part of coursework and contains detailed explanations and graphs. Code and results here can reproduce all key outputs.

---

## Project Features

- Data cleaning and handling of missing values  
- Visualization of key relationships (age, BMI, smoking status, children)  
- Feature engineering: BMI categories, age groups, smoker interactions  
- Machine Learning models applied:  
  - Linear Regression  
  - Decision Tree  
  - Random Forest  
- Model evaluation with MAE, RMSE, and MAPE  
- User-level prediction function to estimate insurance costs for new clients  

---

## Dataset

- Source: Kaggle (Insurance Dataset)  
- Features include: age, BMI, number of children, gender, region, smoker, and charges
